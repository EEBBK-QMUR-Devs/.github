# 欢迎来到 EEBBK QMUR-Devs
# 简介
EEBBK QMUR-Devs全称为EEBBK Qcom-Mtk-Unisoc-Rockchip Developments，是由XiKoTaSu于2025年8月创建的社区性技术组织，主要活动于github及腾讯QQ群组，创建之初的宗旨是促进EEBBK(XTC)旗下的教育平板的进一步深入发展，并保持所有资源永久免费(对于外界倒卖不做过多处理)，目前所涉猎的领域有Android(LineageOS) Linux(PostmarketOS, 6.15+) WOA(Windows On Arm,Project Aloha,Project Silicium)，目前我们已取得多项成果，EEBBK S5运行稳定Linux7.0.9+PostmarketOS(暂停维护)，EEBBK S6自定义4.14安卓内核及Linux7.0(不稳定/未发布，维护中)，EEBBK S6/S7/T3的Windows On Arm(不稳定/未发布)，其他较新机型正在计划中。
